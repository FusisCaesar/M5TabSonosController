If it does not start

  • If no port appears, hold the boot button while resetting the Tab5, then try again.
  • If the screen stays black after flashing, flash the other button. A wrong pick can be flashed over.

The page asks whether to erase the tablet. Erase on a first install. Leave the data in place when you are updating and want to keep the saved Wi-Fi network and the Spotify sign-in.

After it boots, join the Wi-Fi network named like TabSonos... and open the setup page. The steps are in First start.
